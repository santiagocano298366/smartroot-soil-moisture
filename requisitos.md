# Objetivos del trabajo final

El trabajo final busca:

* Formular un problema técnico o empresarial con contexto claro – Proponer el proyecto para uso masivo o empresarial (como si fuese a comercializar esa herramienta).
* Representar datos mediante estructuras de programación.
* Procesar información usando Python.
* Aplicar condicionales, ciclos, listas, diccionarios, arreglos, funciones y comprensiones.
* Calcular indicadores asociados al problema.
* Modelar al menos una parte del sistema mediante programación orientada a objetos.
* Incorporar una simulación sencilla de incertidumbre o escenarios – Método de Montecarlo.
* Interpretar resultados y comunicar técnicamente la solución desarrollada.

# Requisitos mínimos obligatorios

## Planteamiento formal del proyecto

* Título del proyecto.
* Descripción del problema.
* Contexto de aplicación.
* Objetivo general y objetivos específicos.
* Justificación.
* Alcance y limitaciones.
* Datos disponibles o datos simulados.
* Resultado esperado.

## Programación básica en Python

El proyecto debe incluir código en Python directamente relacionado con el problema seleccionado. No se aceptarán ejemplos desconectados del caso de estudio.

* Declaración y uso de variables.
* Carga, entrada o generación de datos.
* Uso de condicionales if, elif y else.
* Uso de ciclos for
* Uso de ciclos while.
* Validación básica de datos.
* Comentarios explicativos en el código.

## Estructuras de datos, arreglos y comprensiones en Python

Cada proyecto deberá evidenciar el manejo de estructuras de datos para almacenar, recorrer, transformar y analizar información relacionada con el caso de estudio.

* Listas, diccionarios o estructuras equivalentes.
* Arreglos con NumPy o DataFrames con Pandas, si aplica.
* Recorrido de datos mediante ciclos.
* Cálculo de mínimo, máximo, promedio y conteos condicionados.
* Operaciones numéricas e interpretación de resultados.
* Uso obligatorio de mínimo tres comprensiones en Python aplicadas a los datos del proyecto.

### Comprensiones obligatorias

El trabajo deberá incluir mínimo tres comprensiones en Python, tales como list comprehension, dictionary comprehension o set comprehension. Estas deberán usarse para filtrar, transformar, clasificar o construir nuevas estructuras de datos y deberán estar explicadas brevemente en el documento técnico.

* List comprehension.
* Dictionary comprehension.
* Set comprehension.
* Comprensión con condición if.
* Comprensión para transformar valores.
* Comprensión para clasificar registros.

No se aceptarán comprensiones genéricas sin relación con el proyecto, por ejemplo listas de números aisladas sin conexión con el problema trabajado.

## Funciones

El estudiante deberá organizar parte del código mediante funciones propias.

* Una función para calcular un indicador.
* Una función para clasificar un resultado.
* Una función para mostrar, retornar o consolidar resultados.

Cada proyecto debe calcular mínimo tres indicadores asociados al problema trabajado.

* Nombre del indicador.
* Fórmula.
* Datos usados.
* Resultado.
* Meta o criterio de referencia.

## Programación Orientada a Objetos

Cada proyecto debe incluir un componente desarrollado mediante Programación Orientada a Objetos. Este componente debe representar elementos reales o conceptuales del problema: sensores, equipos, indicadores, procesos, usuarios o eventos.

* Una clase base.
* Al menos una clase hija o especialización.
* Creación de mínimo dos objetos.
* Atributos asociados al problema.
* Métodos que representen acciones o cálculos.
* Uso de herencia.
* Uso básico de polimorfismo, por ejemplo métodos con el mismo nombre en clases diferentes.
* Explicación de qué representa cada clase y cómo se relaciona con el proyecto.

## Simulación de escenarios o Montecarlo

Cada proyecto debe incorporar una simulación sencilla. Puede ser una simulación de Montecarlo o una simulación de escenarios, siempre relacionada con el problema de estudio.

* Variable incierta.
* Supuesto de simulación.
* Mínimo 1.000 iteraciones si usa Montecarlo.
* Meta o condición de cumplimiento.
* Probabilidad estimada.
* Gráfico o resumen de resultados.
* Interpretación técnica y ejecutiva.

## Visualización de resultados

El proyecto debe incluir diversos elementos visuales (tablero de control) que ayuden a interpretar los resultados.

* Tabla de datos.
* Tabla de indicadores.
* Gráfico de barras.
* Gráfico de línea.
* Histograma.
* Diagrama de flujo.
* Captura de prototipo o interfaz.
